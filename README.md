# 🛒 ShopSphere — AI-Powered E-Commerce Application

ShopSphere is a full-stack e-commerce application built using **React.js, FastAPI, Python, SQLite, and AI**.

## 🚀 Features

* User authentication
* Product browsing and search
* Shopping cart and wishlist
* Address management
* Checkout and payment method selection
* Order management
* AI-powered customer support
* Responsive UI

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, CSS
**Backend:** Python, FastAPI
**Database:** SQLite
**AI:** AI-powered support
**Deployment:** Vercel, Render
